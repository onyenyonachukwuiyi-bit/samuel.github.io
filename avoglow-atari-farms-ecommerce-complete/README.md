# ATARI FARMS Sexy Farming Website

This is a frontend e-commerce prototype for **ATARI FARMS Sexy farming** and its avocado-based beauty and wellness brand **Avoglow**.

The website presents Atari Farms as a climate-smart agribusiness from Uganda, with Avoglow products built around avocado oil, avocado by-products, and organic botanical ingredients.

## Features

- Premium responsive landing page
- Atari Farms logo in the top-left header
- Avoglow logo used as background brand identity
- Product catalogue with PNG product images
- Product category filters
- Add-to-cart drawer with quantity controls
- Checkout enquiry form
- Customer login UI
- Admin dashboard preview
- Company story, mission, vision, and sustainability journey

## Project Files

- `index.html` - main website file containing HTML, CSS, and JavaScript
- `my works/` - logos and product images used by the website
- `atari-farms-github-pages-png.zip` - packaged version ready for upload/deployment
- `convert-jpg-to-png.ps1` - helper script used to convert JPG assets to PNG

## How To Open Locally

Open this file in a browser:

```text
C:\Users\USER\Documents\ONYENYONACHUKWU.html\index.html
```

No build step is required. The website is a static frontend.

## Deployment To GitHub Pages

Upload these items to the root of your GitHub Pages repository:

- `index.html`
- `my works/`

For your repository:

```text
onyenyonachukwuiyi-bit/onyenyonachukwu.github.io
```

After upload, the site should be available at:

```text
https://onyenyonachukwuiyi-bit.github.io/onyenyonachukwu.github.io/
```

If the repository is configured as a user GitHub Pages site, it may also be available at:

```text
https://onyenyonachukwuiyi-bit.github.io/
```

## Notes

The login, checkout, cart, and admin dashboard are frontend demo features. They do not currently connect to a backend database, payment gateway, or real authentication system.

The PNG images were converted from the uploaded JPG files without adding new compression. The original JPG files were left untouched.
